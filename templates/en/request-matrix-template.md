Proof level (R15): **1** file · **2** read from the source · **3a** test · **3b** artefact · **4** live, with **R** (read) or **W** (write).

## How to fill it in

1. Break the request (§1 of `request.md`) and the question-phase answers into short items: one item = one verifiable thing.
2. Paste the **words** of the request in column 2, in quotes.
3. Every item starts **pending**. When a charter is opened for it, write the arc in column 3 and the item ID in the charter's `request_item`.
4. An item that will not be done becomes **excluded**, with a date and who decided. Never delete a row.
5. In the Phase 8 ritual (ch. 08 §4 item 10), re-read the whole request against this table.
