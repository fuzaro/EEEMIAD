## Resumen ejecutivo

La **EEE** es una disciplina de ingeniería de software para sistemas en los que modelos de lenguaje y agentes autónomos construyen código:

1. **Jerarquía de la verdad:** `Plan → ADR → Spec → Code`. El código nunca gana una divergencia por estar ya desplegado.
2. **Pila de DONE estratificada:** prohibición del «done» desnudo (`done@structural`, `done@functional`, `done@gate`, `done@purpose`).
3. **Construcción evolutiva:** rebanada fina → stubs y mocks → flags `off | shadow | enforce` → pruebas con par discordante → arcos que cierran por medición, nunca por declaración.
4. **Reglas del refinamiento empírico:** defensas medidas contra la «familia de respuestas plausibles».
