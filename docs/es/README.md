### Resumen Ejecutivo
La **EEEMIAD** es una metodología de ingeniería de software de alta disciplina diseñada para eliminar las patologías críticas de los desarrollos asistidos por agentes de IA:
1. **La Jerarquía de la Verdad (§2):** `Plan → ADR → Spec → Code`. El código nunca supera a la especificación por estar ya desplegado.
2. **Pila Estratificada de DONE:** Prohibición del "done" desnudo (`done@structural`, `done@functional`, `done@gate`, `done@purpose`).
3. **Flujo de Trabajo Dual-Agent:** División de roles entre agente reflexivo (arquitectura y ADRs) y agente ejecutivo (reality-check e implementación AST).
4. **Las 10 Reglas Empíricas:** Defensas comprobadas contra la "familia de respuestas plausibles".
